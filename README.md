# نظام الفواتير (Invoice System v3.3)

تطبيق سطح مكتب مخصص لإدارة وإنشاء الفواتير الضريبية والإشعارات لشركة جابر حسن سالم المالكي للتقييم، متوافق مع متطلبات ضريبة القيمة المضافة (ZATCA / هيئة الزكاة والضريبة والجمارك) ويدعم فواتير شركة نجم لخدمات التأمين.

## المميزات
- واجهة مستخدم رسومية سهلة مبنية باستخدام Tkinter مع سمة عصرية ودعم اللغة العربية (RTL).
- إنشاء فواتير وإشعارات دائنة بصيغة PDF مع رمز الاستجابة السريعة (QR Code) المتوافق مع متطلبات ZATCA.
- تخطيط PDF متناسق بمحاذاة وهوامش متناظرة (10 ملم) لبيانات البائع والمشتري.
- حفظ وطباعة الفواتير وتوليد تلقائي لأرقام الفواتير المتسلسلة.
- دعم بيانات شركة نجم لخدمات التأمين برقمها الضريبي المعتمد (`300146558310003`).

## المتطلبات وتثبيت الحزم
يتطلب بايثون 3.10 أو أحدث. لتثبيت الحزم المطلوبة:
```bash
pip install -r requirements.txt
```

## التشغيل
لتشغيل التطبيق مباشرة:
```bash
python main.py
```

## بناء ملف تنفيذي (.exe)
يمكن إنشاء نسخة مستقلة لا تتطلب تثبيت بايثون عبر تشغيل:
```cmd
build_app.bat
```
أو عبر PyInstaller:
```bash
pyinstaller --onefile --windowed --name "Invoice System" --add-data "fonts\arabic_font.ttf;fonts" --hidden-import=arabic_reshaper --hidden-import=bidi.algorithm --hidden-import=qrcode --hidden-import=fpdf --hidden-import=tkcalendar main.py
```
النسخة التنفيذية ستكون في مجلد `dist/`.
